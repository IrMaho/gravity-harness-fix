## این پروژه چه مشکلی را حل می‌کند؟

بر اساس بررسی آماری **۴۴۴ ترنسکریپت واقعی Antigravity** (**۱۶ مکالمهٔ اصلی + ۴۲۸ ساب‌ایجنت**، مجموعاً **`106,004` استپ**)، مشخص شد کندی و خطای ایجنت‌ها نه به خاطر ضعیف بودن مدل، بلکه به خاطر چند تلهٔ تکراری در هارنس و محیط اجراست:

- **`2,888` بار** لوپ polling روی `manage_task(status)` به‌جای صبر واکنشی (`<SYSTEM_MESSAGE>`).
- **`5,693` بار** خواندن تکراری فایل یکسان (`34%` کل `read_file`ها).
- **`657` بار** کرش نقل‌قول و دستورات چندخطی بین PowerShell و Python/Node/WSL و **`111` بار** خطای `UnicodeEncodeError (cp1252)` در ویندوز.
- **`535` بار** خطای `edit_file` کورکورانه به خاطر تکرار ادیت بدون خواندن مجدد فایل.
- **اتلاف `۴۰۰` استپ اول** در `/teamwork` سنتی داخل مصاحبه و هماهنگی Coordinator، و هم‌زمان نوشتن `۷` ساب‌ایجنت روی یک دایرکتوری مشترک (`Workspace="inherit"`).
- خطای API/Stream در **`49.3%` ساب‌ایجنت‌ها** (`672.4` دقیقه backoff).

**`gravity-harness-fix`** این مشکلات را با هوک‌های قطعی (`PreToolUse`, `PostToolUse`, `SessionStart`, `Stop`)، قوانین همیشه فعال، مهارت **`/agile-swarm`** و تلمتری دائمی یک‌جا حل می‌کند.

## نصب سریع برای خودتان و دوستانتان (فقط با دو بار کلیک)

1. مخزن را دانلود یا کلون کنید:
   ```sh
   git clone https://github.com/IrMaho/gravity-harness-fix.git
   ```
2. روی فایل **`install.bat`** دوبار کلیک کنید. این اسکریپت به‌صورت خودکار:
   - تمام پروفایل‌های Antigravity روی سیستم (`%USERPROFILE%\.gemini` و تمام پروفایل‌های ایزوله) را پیدا می‌کند و از تنظیمات قبلی بک‌آپ می‌گیرد.
   - پلاگین `gravity-harness-fix` (هوک‌ها + رول‌ها + دو اسکیل `agile-swarm` و `gravity-session-doctor`) را نصب و در `config.json` فعال می‌کند.
   - متغیرهای محیطی `PYTHONIOENCODING=utf-8` و `PYTHONUTF8=1` را دائمی و مسیر `uv` را در WSL2 تنظیم می‌کند.
   - یک تست دود واقعی از هوک می‌گیرد تا از کارکرد بدون باگ مطمئن شود.
3. یک **چت جدید در Antigravity باز کنید** (یا IDE را ری‌استارت کنید).

*(در مک یا لینوکس کافی است بزنید: `python3 scripts/install_harness.py`)*

## چطور مثل کارفرما سریع موازی کار کنیم؟ (`/agile-swarm` — پلن B تک‌اکانت)

به‌جای `/teamwork` پیش‌فرض (که کند و پرمصرف است)، اول پرامپت بنویسید **`/agile-swarm`**:

```text
/agile-swarm صفحات پروفایل، کیف‌پول و تنظیمات را به صورت موازی با تست بساز
```

### مکانیسم اجرایی اسکیل `/agile-swarm`:
1. **تحلیل ۶۰ ثانیه‌ای بدون مصاحبه:** ایجنت اصلی سریع ساختار پروژه را می‌بیند و کار را با **مالکیت فایل کاملاً مجزا** بین **۲ تا ۳ ورکر هم‌زمان** (حداکثر سقف امن برای جلوگیری از ریت‌لیمیت تک‌اکانت) تقسیم می‌کند.
2. **قانون WS1 vs WS3:**
   - اگر ماژول‌ها و فایل‌ها جدا باشند: **۲ تا ۳ کدنویس موازی**.
   - اگر روی یک دیتابیس زنده یا یک فایل هسته مشترک کار می‌کنید: **۱ کدنویس + ۱ ریویوئر/تست‌نویس موازی**.
3. **ایزولاسیون اجباری با `Workspace="share"`:** هوک [`guard_and_log.py`](../plugin/hooks/guard_and_log.py) به‌طور خودکار جلوی باز شدن هم‌زمان ورکرهای کدنویس روی `Workspace="inherit"` را می‌گیرد تا فایل‌های همدیگر را خراب نکنند. هر ورکر شاخهٔ جدا (`agile/<slice>`) دارد، تست سریع `۵–۳۰` ثانیه‌ای خودش را پاس می‌کند و کامیت می‌زند.
4. **نتیجهٔ بنچمارک واقعی (اپ فلاتری ۱۰ صفحه‌ای `PulseHub`):**
   - **زمان کل از پوشه خالی تا ادغام و تست نهایی:** **`12.3` دقیقه**
   - **سرعت ۳ ورکر موازی:** `4.38m` / `4.75m` / `5.95m`
   - **خروجی:** **`5,804` خط کد واقعی Dart** در `19` فایل (`10` صفحه کامل + state + `4` فایل تست)
   - **تعداد مرج کانفلیکت / Polling / backoff API:** **`0`** / **`0`** / **`0.0` دقیقه**
   - **تحلیل استاتیک و تست‌ها:** `0 issues` و **`11/11` تست پاس**.

## ابزار Worktree دستی برای تست‌های سنگین Docker/CI

اگر خواستید یک تست سنگین ۱۵ دقیقه‌ای را در پوشهٔ کناری اجرا کنید تا پنجرهٔ اصلی قفل نشود:

```bat
agile-worktree.bat create C:\path\to\repo slice-a slice-b wt-ci
agile-worktree.bat list C:\path\to\repo
agile-worktree.bat cleanup C:\path\to\repo --delete-branches
```

## عیب‌یابی مستمر (`gravity-session-doctor`)

- خطاها، ادیت‌های ناموفق، لوپ‌ها و مشکلات جدید به‌طور خودکار در مسیر امن **`logs/session-issues.jsonl`** و **`logs/latest-summary.md`** ثبت می‌شوند (در `.gitignore` مخفی است تا هیچ دیتای شخصی به گیت‌هاب نرود).
- روی **`audit_all_conversations.bat`** دوبار کلیک کنید یا داخل چت بنویسید:
  > *«با gravity-session-doctor لاگ مشکلات هارنس را بررسی کن و اگر خطای تکراری هست براش فیکس و تست اضافه کن»*
- برای حذف کامل پلاگین از **`uninstall.bat`** استفاده کنید.
